# 阅读模块

本地阅读支持围绕 TXT 与 EPUB、目录、分页、阅读进度和恢复展开。已实现能力应在 UI 调整时保留；对复杂排版、章节图像和设备差异的支持范围以当前验证结果为准。

阅读相关页面包括阅读器、阅读设置、目录、书内搜索和朗读设置。阅读记录由会话、按日明细和按书汇总三层数据组成；旧版本地记录会迁移到会话层。E 端 r242 已核验隔离跨午夜样例按 `details.date` 分日显示，但真实跨午夜持久化、扫描修复、字数统计和别名合并仍未完成。启用偏好键 `legado_read_records.enabled` 使用字符串 '1'/'0'。功能队列优先处理本地阅读行为和数据一致性；朗读设置页面不代表 TTS 服务已经接入。

对阅读改动，至少核对当前书目、章节与阅读位置的保存和恢复，以及受影响的目录、搜索、控制层和设置。没有设备验证时，应把该范围记为未验证，不用构建成功推断运行行为。

各模块的当前状态见 [进度摘要](PROGRESS.md) 和 [验证记录](VALIDATION.md)。
