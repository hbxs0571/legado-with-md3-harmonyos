# 页面与模块概览

主导航包含首页、书架、发现、订阅和我的。主导航共享底栏；进入当前模块的直接页面、弹层、空态和返回路径应可用。更深的业务功能按实际接入状态呈现。

| 模块 | 主要页面范围 | 边界 |
| --- | --- | --- |
| 首页 | 最近阅读、统计、目标和快捷入口 | 在线服务入口不代表服务已接入 |
| 书架 | 本地书目、导入、详情、搜索和阅读入口 | 文件由系统选择器提供 |
| 发现 | 分类、分组、空态和结果页 | 在线搜索尚未接入时不得伪造结果 |
| 订阅 | 订阅页、规则列表和源管理入口 | RSS 拉取与登录按实际状态标记 |
| 我的 | 阅读记录、书签、规则、缓存、文件与关于 | 每项能力分别核验 |
| 设置 | 主题、阅读、朗读、备份、隐私及相关配置 | 页面控件的预览状态不等于已保存 |
| 阅读 | 阅读页、阅读设置、目录、书内搜索和朗读设置 | 以当前进度摘要说明完成和待验范围 |

本表是导航索引，不代表所有页面已完成迁移或逐项验收。当前状态见 [进度摘要](PROGRESS.md)，构建与设备结果见 [验证记录](VALIDATION.md)。
