# 当前进度

更新：2026-10-28，对应 E 端 r258 源码检查点（r258 仅源码接入，设备验收未完成）。此摘要不含本机续接记录、历史证据、截图、书名、设备地址、日志、HAP 或备份。

## E 端已接入并核验

- r251–r254 接入系统字体选择、段落/行距与字距、两端/底部对齐、正文粗斜体、阴影和下划线等阅读设置。E 端 HOS 模拟器按记录范围检查系统字体选择冷启动、对齐行为和部分正文效果及读回。源码支持导入 TTF/OTF 到应用沙箱，但真实字体文件导入、CJK fallback 和 EPUB 字体仍未验。
- r255 修复 Android ZIP 同一 `config.xml` 中 `readConfig` 与 `themeConfig` 设置门控相互影响的问题。E 端 HOS 模拟器检查了两类各自包含/忽略的四种组合。
- r256 修复隐藏分组页签后无法切换书架筛选的问题；E 端验证了从分组管理切换到“本地未分组”、面板关闭及强停冷启动保持。
- r257 在书架 UI 说明私有标记和分组刷新尚未生效；HAP 构建、保留数据覆盖安装和启动检查通过。测试设备没有自定义分组，因此卡片说明未被设备直接验收。
- 新增 Hypium 首页启动冒烟测试目标；测试 HAP 可构建，但用例尚未运行，不代表设备业务回归通过。
- Android `bookGroup.json` 书架分组导出/导入逻辑已接入源码；外部 Android ZIP 的完整分组导入导出仍待设备验收。
- 本地阅读记录有会话、按日明细和按书汇总三层仓储，并迁移旧版本地记录；Android ZIP 中的历史记录目前仅作兼容归档保留，未导入原生记录页。
