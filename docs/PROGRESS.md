# 当前进度

更新：2026-10-28，对应 E 端 r245 稳定检查点与 r243 正文选择功能的公开摘要。不包含本机 CURRENT、history/evidence、截图、书名、设备地址或备份内容。

## E 端已接入并核验

- r245 书架分组手动整合已同步：分组管理与编辑、排序菜单、刷新设置和“私有”标记保存/读回已在 E 端 HOS 通过 HDC+OCR 检查；临时测试分组已清理。
- r243“允许选择正文”设置已在 E 端接入设置、Preferences 持久化和 ReaderPage 的 selectable 状态；开关保存/读回与正文选择行为已核验。
- 既有 TXT/EPUB、本地书架、阅读记录三层、TXT 目录规则和 Android ZIP 兼容实现保留。书架 v13 分组/元数据与 v14 目录分卷字段继续沿用已有兼容布局。
- 本地阅读记录开关仍使用 `legado_read_records.enabled` 字符串 `'1'`/`'0'`。N 端 API 26 测试不是 E 端或 API 12 证据。

## 尚未完成或未验证

- 分组封面尚未实际选图并冷启动读回；网格卡片拖拽未在 E 端设备确认；分组排序方式目前只保存设置，尚未验证它会改变书架书目列表顺序。
- “私有”分组目前只保存标记；未迁移 Android 的访问验证/授权逻辑，不是密码保护或访问控制。
- 书架刷新设置持久化已核验，但该开关对 HOS 刷新行为的实际影响未验证。
- 阅读记录跨午夜隔离样例已验证按 `details.date` 分日显示；真实跨午夜记录持久化、扫描/修复提示未在 E 端验。阅读字数恒为 0，书籍别名合并未迁移。
- API 12 真机兼容尚未验证。N 端 API 26 测试不得归为 E 端结果。
- 标注、书签和正文选择只覆盖验证记录所列操作；未宣称所有内容格式、系统版本和异常路径均完成回归。
