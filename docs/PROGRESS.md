# 当前进度

更新：2026-10-26。对应公开源码快照；仅汇总可公开的实现状态，不包含用户书籍、设备截图、备份文件或本机路径。

## 本轮增量

- 阅读器顶栏和底栏配置已补齐 Android 对应的 28 项动作池，支持启用、隐藏、排序、保存和按书籍类型展示适用项。尚未迁移的动作会提示状态，不会假装操作成功。
- 本地书签已覆盖创建、备注编辑、列表、删除和章节位置恢复；正文处理、替换规则与按书重分段已有实现及模拟器记录。
- 订阅页的订阅源管理入口已进入独立页面，并完成空列表导航和系统返回验证；RSS 新增、编辑、导入、分组和筛选的数据业务尚未接入。
- 订阅空态上划/下划交互有模拟器记录；Android 与 HarmonyOS 当前滚动行为仍存在差异，待后续对照。
- 阅读器五路由仍处于实现中。进度模式持久化、目录当前章定位、目录标题替换/字数开关、书内搜索与朗读设置返回逻辑有源码增量；TTS 播放尚未接入。
- 图片点击行为设置已复用 Android `clickImgWay` 并随兼容备份保存。HOS 模拟器上，真实 EPUB 封面可打开本地预览并返回同一阅读页；测试 EPUB 没有章节内嵌图片，因此该场景尚未验证。设置已恢复默认经典模式。

## 当前未完成

- P1 整体 UI 与交互验收尚未完成；阅读器、阅读设置、目录、书内搜索和朗读设置五路由仍未验收通过。当前重点是审计阅读设置本地逻辑，并补齐这些路由的设备验收。
- P2 本地阅读和 P4 备份恢复已有实现及历史验证；最新快照的变更需要完成受影响的回归。EPUB 复杂排版、章节内嵌图片及未迁移 Android 备份类别仍有限。
- 在线书源、RSS 数据、AI、TTS、WebDAV 和云同步尚未接入；不会由这些入口执行网络请求。
- 仓库资源清单当前统计 133 个 SVG，其中 31 个图标有 AndroidX Material / Apache-2.0 来源记录、10 个图标来源仍待确认，详见 [资源许可清单](RESOURCE-LICENSES.md)。
