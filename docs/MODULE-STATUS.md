# 模块验收摘要

此摘要对应 2026-10-28 的 E 端整合源码基线，不含本机续接记录、用户书名、阅读位置、设备标识或备份内容。

| 模块 | 当前可确认范围 | 尚未验收或未接入 |
| --- | --- | --- |
| 导航与 UI | 首页、书架、发现、订阅、我的及多个直接页面已有实现 | 全部页面的视觉与设备交互尚未完整验收；未迁移动作继续显示真实状态 |
| 本地阅读 | TXT/EPUB、本地书架、目录、分页、进度保存和恢复已有实现；E 端书架 v12 元数据、眼保设置与阅读进度变化已保留在本次同步源码 | 阅读器、目录、书内搜索和设置等路由仍需整页核对；复杂 EPUB 排版和章节内嵌图片支持有限 |
| 替换净化规则 | 管理列表、编辑/分组、导入导出、按书启停、正文应用和 ZIP 规则映射均已接入源码 | E 端只验证到规则管理空状态；尚未在 E 端创建规则、文件导入/导出或做 ZIP 规则往返全流程 |
| 阅读设置 | 阅读行为、控制项、阅读进度和眼保设置由本地代码承载 | 每个页面控件的持久化和真实阅读行为需按模块逐项验收 |
| Android ZIP | 预览、校验及部分书目、进度、配置和替换规则字段映射存在 | 未映射数据不自动激活原生业务；替换规则 E 端全往返尚未验收；不提供完整数据库语义或跨类别事务回滚 |
| 在线服务 | 部分界面入口可见 | 书源抓取、RSS 拉取、TTS、AI、WebDAV、云同步和 Web 服务未接入 |
| 开源与资源 | 许可、隐私、使用说明和已核验资源来源已纳入公开仓库 | 无发行签名安装包；资源和隐私范围应随未来新增内容重新审查 |

模块状态不等同于全部功能完成。构建、资源许可和设备核验分别见 [验证记录](VALIDATION.md)、[已知问题](KNOWN-ISSUES.md) 与 [资源许可清单](RESOURCE-LICENSES.md)。
