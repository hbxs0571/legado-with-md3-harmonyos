# 模块验收摘要

此摘要对应 2026-10-27 的公开源码基线，不含本机续接记录、用户书名、阅读位置、设备标识或备份内容。

| 模块 | 当前可确认范围 | 尚未验收或未接入 |
| --- | --- | --- |
| 导航与 UI | 首页、书架、发现、订阅、我的及多个直接页面已有实现 | 全部页面的视觉与设备交互尚未完整验收；未迁移动作继续显示真实状态 |
| 本地阅读 | TXT/EPUB、本地书架、目录、分页、进度保存和恢复已有实现；书签、正文处理与替换规则有对应实现 | 阅读器、目录、书内搜索和设置等路由仍需整页核对；复杂 EPUB 排版和章节内嵌图片支持有限 |
| 阅读设置 | 阅读行为、控制项和设置状态由本地代码承载 | 每个页面控件的持久化和真实阅读行为需按模块逐项验收 |
| Android ZIP | 预览、校验及部分书目、进度和配置字段映射存在 | 未映射数据不自动激活原生业务；不提供完整数据库语义或跨类别事务回滚 |
| 在线服务 | 部分界面入口可见 | 书源抓取、RSS 拉取、TTS、AI、WebDAV、云同步和 Web 服务未接入 |
| 开源与资源 | 许可、隐私、使用说明和已核验资源来源已纳入公开仓库 | 无发行签名安装包；资源和隐私范围应随未来新增内容重新审查 |

模块状态不等同于全部功能完成。构建、资源许可和设备核验分别见 [验证记录](VALIDATION.md) 与 [资源许可清单](RESOURCE-LICENSES.md)。
