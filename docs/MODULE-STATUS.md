# 模块验收摘要

此摘要对应 2026-10-28 的 E 端 TXT 目录规则整合公开快照，不含本机续接记录、用户书名、阅读位置、设备地址或备份内容。

| 模块 | 当前可确认范围 | 尚未验收或未接入 |
| --- | --- | --- |
| 导航与 UI | 首页、书架、发现、订阅、我的及多个直接页面已有实现 | 全部页面的视觉与设备交互尚未完整验收；未迁移动作继续显示真实状态 |
| 本地阅读 | TXT/EPUB、本地书架、目录、分页、进度保存和恢复已有实现；书架 v13 分组/元数据保留，v14 持久化目录分卷标记与所选规则，并兼容 N 端旧字段布局 | 阅读器、目录、书内搜索和设置等路由仍需整页核对；复杂 EPUB 排版和章节内嵌图片支持有限 |
| TXT 目录规则 | 规则管理、内置规则导入、JSON 导入导出、按规则导入 TXT、分卷识别/折叠、规则字段 ZIP 映射已接入；E 端已核验内置规则重启保留、规则文件往返、TXT 分卷和进度持久化 | 书架更新目录设备验证、完整 CRUD/批量操作覆盖、非空规则应用备份恢复仍待验；当前只验证合成 ZIP 单条规则恢复与空规则应用备份读回 |
| 替换净化规则 | 管理列表、编辑/分组、导入导出、按书启停、正文应用和 ZIP 映射已接入源码 | 完整设备 CRUD、批量操作及非空规则应用备份恢复仍需按功能单独验收；同步正则超时字段尚未生效 |
| 阅读设置 | 阅读行为、控制项、阅读进度和眼保设置由本地代码承载 | 每个页面控件的持久化和真实阅读行为需按模块逐项验收 |
| Android ZIP | 预览、校验及部分书目、进度、配置和规则映射存在；TXT 目录规则的合成单条恢复与空规则应用备份读回已核验 | 不提供完整 Android 数据库语义或跨类别事务回滚；非空 TXT 规则应用备份恢复未验 |
| 在线服务 | 部分界面入口可见 | 书源抓取、RSS 拉取、TTS、AI、WebDAV、云同步和 Web 服务未接入 |
| 开源与资源 | GPL-3.0 许可、隐私、使用说明及已核验资源来源已纳入公开仓库 | 无发行签名安装包；资源和隐私范围应随未来新增内容重新审查 |

以上状态不等同于全部功能完成。设备检查方法、未验范围、构建和资源来源分别见[验证记录](VALIDATION.md)、[已知问题](KNOWN-ISSUES.md)与[资源许可清单](RESOURCE-LICENSES.md)。
