# 鸿蒙迁移术语

**原生功能**：用户能在 HarmonyOS 页面完成对应操作，且需要保存的数据在重新启动后仍保持。页面外观或预览不等于功能完成。
_避免_：把页面壳或预览称为功能完成

**Android ZIP 数据映射**：把 Android 备份中语义明确且受支持的数据写入原生功能，并通过实际导入和结果核对验证。
_避免_：把原条目保存为兼容数据就称为已接入

**安全兼容**：识别、预览、忽略或原样保留未迁移的归档类别，不执行其中的规则，也不调用外部服务。
_避免_：把未迁移类别写成功能恢复

**当前模块**：功能队列中一次只处理的一个明确能力或一种 ZIP 数据类别，包含其直接页面、数据和受影响回归。
_避免_：把整个阶段或整站扫描当作当前模块

**模块验收**：对一个明确功能及其直接页面、数据和受影响行为进行验证，并记录已验和未验范围。

**候选能力**：已知但不在当前功能队列中的能力，不应描述为已排期或已接入。
_避免_：把候选能力写成下一步或已排期
