# 鸿蒙迁移术语

**N 端 / E 端**：2026-10-28 r258 移交前两台并行开发机的代称。N 端是本仓库当前所在机器（`N:\HarmonyProjects\legado-with-md3-harmonyos`），承担全部开发与验收；E 端是另一台机器，负责复核与公开上传，已在 r258 检查点停止新增功能并退场。活文档中遗留的「E 端」均为历史事实陈述，保持原样不改写；此后新增记录不再使用该称谓。
_避免_：把历史记录里的「E 端验收」当作当前仍需等待的环节

**原生功能**：用户能在 HarmonyOS 页面完成对应操作，且需要保存的数据在重新启动后仍保持。页面外观或预览不等于功能完成。
_避免_：把页面壳或预览称为功能完成

**Android ZIP 数据映射**：把 Android 备份中语义明确且受支持的数据写入原生功能，并通过实际导入和结果核对验证。
_避免_：把原条目保存为兼容数据就称为已接入

**安全兼容**：识别、预览、忽略或原样保留未迁移的归档类别，不执行其中的规则，也不调用外部服务。
_避免_：把未迁移类别写成功能恢复

**当前模块**：功能队列中一次只处理的一个明确能力或一种 ZIP 数据类别，包含其直接页面、数据和受影响回归。
盘点与实现都以 ZIP 类别为单位，用其忽略项键名作 ID（`bookmark`、`bookGroup`…）。
_避免_：把整个阶段或整站扫描当作当前模块；也避免把当前模块的上游接触面大小当作扩大交付范围的理由

**ZIP 类别**：Android 备份中的一个忽略项键名及其包含的条目，是盘点和兼容度的计量单位。例如 `bookmark` 包含 `bookmark.json` 与 `bookMarking.json`。
_避免_：把功能页面当作类别；把 `config.xml` 整体算作一类（它的键按 `preferenceKeysByCategory` 分摊到各类）

**上游接触面**：某能力在上游源码中引用到它的全部文件集合，按内容引用划定，与交付范围无关。
_避免_：把接触面大小当作要扩大交付范围，或只按文件名枚举

**盘点**：产出对照表、不写业务代码的阶段。完成标准是**覆盖证明**——见下条。
_避免_：一边读源码一边改代码；也避免把「表格自己写完了」当成盘点完成

**覆盖证明**：盘点的完成判据。上游接触面的每一个 `.kt` 文件都必须被显式分配到「已映射到某行」或「已排除 + 理由」二者之一，表格行数由这个分配决定，不由盘点者发现多少决定。
_避免_：用「表中无空行、无待定」当完成标准——行数由盘点者决定，该判据永远可满足，证明的是表格自洽，不是上游被覆盖
_避免_：用「覆盖率百分比」当判据——关键词宽泛会捞进无关文件，收窄又漏间接引用，测出的数字不可信

**完成（三合一）**：一个能力算完成，须同时满足功能对齐、存储对齐、验收记录三项。缺一不可。见 [关系型存储迁移计划](RELATIONAL-STORE-MIGRATION.md) 的「完成判据」节。
_避免_：只把对照表填满就称为完成，或只把数据换了存储就称为完成

**模块验收**：对一个明确功能及其直接页面、数据和受影响行为进行验证，并记录已验和未验范围。

**候选能力**：已知但不在当前功能队列中的能力，不应描述为已排期或已接入。
_避免_：把候选能力写成下一步或已排期

**还原**：按 Android 对应页面的源码结构，在 ArkUI 中重建布局区域、控件、文案与图标，并使其可用。操作步骤见 [UI 还原流程](UI-RESTORE.md)。
_避免_：把画出一个相似页面称为还原

**校准**：把已还原的页面与原版置于同一内容、主题、字号和控制层状态下比对并消除差异。分整页同态对照与七项验收两级，不做逐像素门槛。
_避免_：用任意截图对比代替同态对照

**同态对照**：使用同一内容、章节锚点、主题/字号、控制层状态并记录视口与密度后的两端比较。
_避免_：只因同一本书就视为状态一致

**迁移**：把原版功能在 HarmonyOS 上以原生方式实现到可实际操作且数据可持久化，或按安全兼容规则明确归类为保留/忽略。
_避免_：把页面壳、预览或兼容占位数据称为迁移完成

**未迁移**：原版存在、当前尚未接入的能力。须保留图标、文字、行和必要目的页 UI 并明确标注，点击不伪造成功或实际执行。
_避免_：把未迁移项隐藏，或让按钮看起来可用

**占位**：为尚未接入的功能保留的结构与视觉位置，本身不含真实业务。不得用统一占位页代替原版完整 UI。
_避免_：用占位页冒充已还原页面

**弹层**：从页面浮出的临时界面层，包括底部面板、居中对话框与浮窗形态。Android 侧对应 `*Sheet*.kt` 与 `*Dialog*.kt`，基座为 `AppModalBottomSheet`。
_避免_：与页面导航混为一谈
